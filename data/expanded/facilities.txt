# Player-buildable industrial facilities.
#
# facility "<name>"
# 	description `<text shown in the Industry panel; keep it to about 40 words>`
# 	cost <credits to build, and to build each extra unit>
# 	upkeep <credits per day, per unit>
# 	input "<trade commodity>" <tons per day, per unit>     (any number, optional)
# 	output "<trade commodity>" <tons per day, per unit>    (any number)
# 	storage <maximum tons of each commodity, per unit>
# 	planet "<planet>" ["<planet>" ...]                     (buildable on these planets)
# 	attributes <attribute> [<attribute> ...]               (or on planets with any of these)
# 	uninhabited                                            (or on any uninhabited planet)
# 	warehouse <tons>                                       (warehouse space it adds to its planet, per unit)
# 	station                                                (founds a new station in the system instead;
#                                                          its modules use: attributes "player station")
# 	requires "<condition>"                                 (only once the player has this condition)
# 	flavor `<status report; <planet> becomes the planet name>`  (any number)
#
# Production chains:
# 	Mining Outpost, Ore Extractor -> Metal
# 	Deep Core Mine -> Heavy Metals
# 	Hydroponics Farm -> Food
# 	Petrochemical Plant -> Plastic
# 	Textile Mill: Plastic -> Clothing
# 	Machine Works: Metal + Plastic -> Equipment
# 	Pharmaceutical Lab: Food + Plastic -> Medical
# 	Electronics Foundry: Heavy Metals + Plastic -> Electronics
# 	Industrial Fabricator: Metal + Electronics -> Industrial
# 	Luxury Workshop: Electronics + Clothing -> Luxury Goods
#
# Produced only, never sold (unlocked by the story in "varga claims.txt"):
# 	Survey Drill -> Core Samples
# 	Crystal Bore -> Pressure Crystals
# 	Isotope Separator: Heavy Metals -> Refined Isotopes
# 	Varga Deep Bore -> Heavy Metals + Pressure Crystals
