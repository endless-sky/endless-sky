# Noto Sans KR

`NotoSansKR-VF.ttf` is part of the Noto font project and is distributed under
the SIL Open Font License, version 1.1. The license text is available at
<https://scripts.sil.org/OFL>.

The font is used as the Unicode fallback for the bitmap UI fonts. The original
bitmap fonts remain the default for ASCII text.
